# Lumina Calculator

A polished, responsive calculator built with **HTML, CSS, and vanilla JavaScript**. It includes standard arithmetic, scientific functions, keyboard support, calculation history, theme switching, and a mobile-friendly interface.

## Features

- Standard mode for everyday arithmetic
- Scientific mode with trigonometry, logarithms, powers, roots, constants, and factorial
- Degree/radian toggle for trigonometric functions
- Real-time expression preview and result display
- Calculation history with one-click result reuse
- Keyboard support: numbers, operators, Enter, Escape, Backspace, and parentheses
- Responsive glassmorphism UI with light/dark theme support
- No frameworks, build tools, or dependencies required

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0-9`, `.`, `+`, `-`, `*`, `/`, `(`, `)` | Enter values and operators |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last character |
| `Escape` | Clear the current calculation |
| `Delete` | Clear everything |

## Project files

- `index.html` — semantic application layout and calculator controls
- `styles.css` — responsive visual system, themes, and component styling
- `script.js` — calculator engine, UI state, keyboard handling, and history
